# Project Overview

A simple mini e commerce website for practicing my front-end development skills.

# Tech Stack

#### Front-End

Vite, TypeScript, React, Tailwind

#### State Management

React Context API

#### Testing

Vitest

# Functional Requirements

User can see all products in home page.
User can go to a specific product page and see information about that product.
User can add a product to his basket.
User can search a specific product.
User can filter products by the product type, (Laptop, Tablet, Mobile)
User can filter products by Manufacturer (Apple, Nokia, Samsung, HTC).
User can sort products by their price.
User can view the shopping cart with all added items.
User can remove a product from the basket.
User can change the quantity of an item in the basket.
User can see the total calculated price of the basket.

# Non-Functional Requirements

Search function must feel responsive.
Website should have a responsive layout on different screen size.

# Product Details

Products have Title, ID, Manufacture name, Category, Price, Image, Screen Size, OS, Description
